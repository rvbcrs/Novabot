# OpenNova

[![Sponsor](https://img.shields.io/badge/Sponsor-%E2%9D%A4-ea4aaa?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/rvbcrs) [![Buy Me a Coffee](https://img.shields.io/badge/Buy%20Me%20a%20Coffee-%E2%98%95-ffdd00?logo=buymeacoffee&logoColor=black)](https://buymeacoffee.com/rvbcrs) [![PayPal](https://img.shields.io/badge/PayPal-donate-00457C?logo=paypal&logoColor=white)](https://paypal.me/rvbcrs)

A self-hosted replacement for the Novabot mower cloud. Your mower and charging
station connect to a server on your own network, so they keep working now that
the company behind them is gone.

**Everything is on the wiki: [wiki.ramonvanbruggen.nl](https://wiki.ramonvanbruggen.nl)**

- [Installing OpenNova](https://wiki.ramonvanbruggen.nl/guide/docker/): where to run it, one `docker-compose.yml`, one line to change
- [DNS Setup](https://wiki.ramonvanbruggen.nl/guide/dns-setup/): pointing the mower at your server
- [First Run](https://wiki.ramonvanbruggen.nl/guide/getting-started/): the app, the certificate, the first map
- [Raspberry Pi Installer](https://wiki.ramonvanbruggen.nl/guide/raspberry-pi-installer/): a ready-made SD card, no Docker knowledge needed
- [Troubleshooting](https://wiki.ramonvanbruggen.nl/user-guide/troubleshooting/)

The wiki's source is the [`docs/`](docs/) folder in this repository; edit it there.

Bug reports and feature requests: [GitHub Issues](https://github.com/rvbcrs/Novabot/issues). When something does not connect, attach the output of **Why is it not coming online?** from the admin panel.

This project is for personal, non-commercial use with Novabot devices you own. It is beta software; your mower is an expensive device, test carefully.
